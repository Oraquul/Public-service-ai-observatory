# Six questions before you scale

Use this before a pilot is widened. A completed sheet is a thinking aid. It is not a measured case, and it is not permission to deploy.

The questions are the journal’s editorial promise. Write the answer a sceptical colleague could check. If a line has no source, write “unknown” rather than a rounded success.

1. **What service problem was addressed?** Name the users, the task and the decision this work is meant to support.
2. **What changed?** Separate the workflow change from any claimed result. Say what the previous process was.
3. **What evidence supports the result?** Give the method, the period, the denominator and the evidence label. A demonstration is not a measurement.
4. **What did it cost?** Include human review and correction, licences, hosting and the cost of keeping sources current. Say what was left out.
5. **What could go wrong?** Include a wrong answer, a person who cannot use the channel, a stale source and a decision the tool must not make.
6. **What would another institution need to repeat it?** Name the owner, the authority, the data, the fallback and the local test.

Compare the AI workflow with the current service and with a simpler alternative, such as a better index or a spreadsheet rule. Time released is staff capacity. It is not automatically a cash saving.
